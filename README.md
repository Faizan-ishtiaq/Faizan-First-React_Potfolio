## ✨ Features

- ⚡ **Multi-page React app** with React Router DOM
- 📊 **Animated skill bars** — CSS transition on mount via `useEffect`
- 🗓️ **Journey timeline** — shows my dev progress from 2023 to 2025
- 🃏 **Project cards** with live demo links for every project
- 🔧 **Services section** with tools & tech logos
- 📱 **Fully responsive** — hamburger menu on mobile with slide-in drawer
- 📄 **Resume download** button (PDF)
- 🦶 **Footer** with quick links, social links & contact info

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/Faizan-ishtiaq/Faizan-First-React_Potfolio.git

# 2. Navigate into the project
cd Faizan-First-React_Potfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
